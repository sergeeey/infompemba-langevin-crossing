- ✅ Кривая KL_hot пересекает KL_cold
- ✅ Пересечение стабильно (≥50 шагов)
- ✅ p-value < 0.01 (t-тест Уэлча)

**Эффект НЕ обнаружен если:**
- ❌ Кривые не пересеваются
- ❌ Пересечение есть, но p-value > 0.05

## 🔧 Решение проблем

### Проблема: CUDA Out of Memory
**Решение**: Уменьшите batch_size в конфиге:
```yaml
data:
  batch_size: 32  # или даже 16
```

### Проблема: Эксперимент слишком медленный
**Решение**: Включите mixed precision:
```yaml
hardware:
  mixed_precision: true
```
Или используйте VanillaSGD вместо LangevinFisher (в 2-3 раза быстрее).

### Проблема: GPU перегревается (>85°C)
**Решение**:
1. Ограничьте мощность: `nvidia-smi -pl 70`
2. Используйте lowpower конфиг
3. Поднимите заднюю часть ноутбука для лучшей вентиляции
4. Включите максимальные обороты вентиляторов через MSI Center

### Проблема: Эксперимент прервался на середине
**Решение**: Частичные результаты сохранены. Можно запустить заново с `--no-confirm` и новым именем эксперимента.

### Проблема: KL(hot) не > 5.0
**Решение**: Увеличьте параметры горячей инициализации:
```yaml
initialization:
  hot_gain_multiplier: 4.0    # Было 3.0
  hot_laplace_scale: 0.8      # Было 0.5
```
