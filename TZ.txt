# ТЕХНИЧЕСКОЕ ЗАДАНИЕ

## 1. Общие сведения

### 1.1. Наименование проекта
**"InfoMpemba: Верификация ускоренной сходимости нейронных сетей при намеренно дестабилизированной (горячей) инициализации через призму информационной геометрии Фишера"**

### 1.2. Цель работы
Разработать и выполнить вычислительный эксперимент, однозначно подтверждающий или опровергающий существование **классического аналога сильного эффекта Мпемба** в динамике обучения нейронных сетей, описываемой стохастическим дифференциальным уравнением Ланжевена в метрике Фишера.

### 1.3. Основание для проведения работ
Гипотеза Chief Scientific Synthesizer (Версия 2.1), базирующаяся на синтезе:
- Квантовой термодинамики открытых систем (Gorini–Kossakowski–Sudarshan–Lindblad, эффект Мпемба);
- Информационной геометрии Амари (дуальная связность, метрический тензор Фишера);
- Стохастической теории оптимизации (SGD как градиентный поток с мультипликативным шумом).

### 1.4. Требования к воспроизводимости
Весь код, конфигурации, сиды генераторов псевдослучайных чисел (PRNG) и версии библиотек должны быть зафиксированы в `Dockerfile` или `environment.yml`. Результаты должны воспроизводиться побитово при запуске на идентичном железе (CUDA 12.1+).

## 2. Теоретическая база и математический аппарат (Референс)

### 2.1. Формулировка гипотезы
Существует конечное время \( t_c > 0 \) такое, что для двух траекторий обучения \( \boldsymbol{\theta}_h(t) \) (горячая) и \( \boldsymbol{\theta}_c(t) \) (холодная) с начальными условиями:
\[
D_{\text{KL}}(\boldsymbol{\theta}_h(0) \| \boldsymbol{\theta}^*) > D_{\text{KL}}(\boldsymbol{\theta}_c(0) \| \boldsymbol{\theta}^*)
\]
выполняется строгое неравенство:
\[
D_{\text{KL}}(\boldsymbol{\theta}_h(t_c) \| \boldsymbol{\theta}^*) < D_{\text{KL}}(\boldsymbol{\theta}_c(t_c) \| \boldsymbol{\theta}^*)
\]
где \( D_{\text{KL}} \) — дивергенция Кульбака-Лейблера между предсказаниями модели и целевым байесовским распределением эталонной модели \( \boldsymbol{\theta}^* \).

### 2.2. Ключевые метрики для мониторинга
1. **Эмпирическая KL-дивергенция** (на валидационной выборке).
2. **След эмпирической матрицы Фишера** \( \text{Tr}(\hat{\mathbf{F}}) \).
3. **Спектральная информационная температура**:
   \[
   T_{\text{info}}(t) = \frac{1}{k} \sum_{i=1}^k \frac{1}{\lambda_i^{(t)} + \epsilon}
   \]
   где \( \lambda_i \) — собственные значения оператора \( \mathbf{F}^{-1/2} \nabla^2 L \mathbf{F}^{-1/2} \) (вычисляются через Lanczos-итерации), \( k=100 \), \( \epsilon=10^{-6} \).

### 2.3. Необходимое условие проявления эффекта
Наличие **негауссовых тяжелых хвостов** в распределении стохастического градиентного шума. Обеспечивается малым размером батча \( B=16 \) и отсутствием Batch Normalization (только LayerNorm или отсутствие нормализации).

## 3. Программная архитектура и компоненты

Система должна состоять из четырех изолированных модулей.

### 3.1. Модуль 1: Генератор начальных состояний (`initializers.py`)
**Задача:** Создать три набора весов для заданной архитектуры.

| Кодовое имя | Физическая аналогия | Метод генерации | Требование к параметрам |
| :--- | :--- | :--- | :--- |
| `theta_star` | **Ground Truth** | Обучить стандартно 50 эпох с AdamW и косинусным отжигом до сходимости `loss < 0.05`. Зафиксировать. | **Неизменна**. Используется только для расчета KL. |
| `theta_cold` | **Переохлажденная жидкость** | Взять `theta_star` и добавить гауссов шум \( \mathcal{N}(0, 0.01^2) \) к каждому тензору. | \( D_{\text{KL}}(\text{cold} \| \text{star}) < 0.5 \). |
| `theta_hot` | **Перегретый пар** | Инициализация Kaiming Uniform с коэффициентом усиления `gain * 3.0` + добавление импульсного шума (распределение Лапласа) с масштабом \( 0.5 \). | \( D_{\text{KL}}(\text{hot} \| \text{star}) > 5.0 \). |

### 3.2. Модуль 2: Симулятор SGD-Ланжевена (`langevin_sgd.py`)
**Задача:** Реализовать цикл обучения с фиксацией траектории.
**Алгоритм шага:**
```python
def step(model, batch, lr, noise_scale):
    loss = criterion(model(batch.x), batch.y)
    grad = autograd(loss)
    # Вычисление диагонали Фишера (опционально, через BackPACK)
    fisher_diag = compute_fisher_diag(model, batch)
    # Ланжевеновское обновление с метрикой Фишера
    with torch.no_grad():
        for p, g, f in zip(model.parameters(), grad, fisher_diag):
            # Масштабированный шум
            noise = torch.randn_like(p) * sqrt(2 * lr / batch_size) / (f.sqrt() + 1e-8)
            p.data -= lr * (g / (f + 1e-8)) + noise
    return loss
```
**Важно:** Должна быть опция переключения между **SGD (базовый)** и **Langevin-Fisher (продвинутый)** для абляционных тестов.

### 3.3. Модуль 3: Метрический анализатор (`fisher_metrics.py`)
**Задача:** Вычисление тяжелых метрик каждые \( N_{\text{eval}} = 10 \) шагов.
**Требования:**
1. **KL-дивергенция:** Использовать 10000 примеров из валидационного набора. Вычислять как `F.kl_div(log_softmax(current), softmax(star), reduction='batchmean')`.
2. **След Фишера:** Использовать библиотеку **BackPACK** с расширениями `DiagGGNExact`. Суммировать диагональные элементы по всем слоям.
3. **Относительный Гессиан:** Реализовать операторно-векторное произведение `Hv` без построения матрицы. Для вычисления 100 крайних собственных значений использовать `scipy.sparse.linalg.eigsh` с режимом `LM` (Largest Magnitude).

### 3.4. Модуль 4: Статистический контроллер (`mpemba_runner.py`)
**Задача:** Запустить \( N_{\text{runs}} = 1000 \) независимых траекторий для "холодного" и "горячего" старта.
**Управление случайностью:**
- Глобальный сид устанавливается как `base_seed`.
- Сид для запуска `i` вычисляется как `base_seed + i`.
- **Критично:** Использование `torch.use_deterministic_algorithms(True)`.

## 6. Критерии успешного подтверждения гипотезы (Статистический анализ)

После сбора данных по всем \( N_{\text{runs}} \) выполняется следующий пайплайн анализа (реализуется в `analysis.ipynb`):

1. **Усреднение по ансамблю**:
   Для каждого `step` вычисляем среднее значение `kl_div_star` и 95% доверительный интервал (через бутстрэп).

2. **Детекция пересечения**:
   Находится первый момент времени \( t_c \), где выполняется:
   \[
   \text{Mean}(\text{KL}_{\text{hot}})_{t_c} < \text{Mean}(\text{KL}_{\text{cold}})_{t_c}
   \]
   и это неравенство сохраняется в течение следующих 50 шагов.

3. **Проверка статистической значимости**:
   - Применяется **t-критерий Уэлча** (независимые выборки) на шаге \( t_c \).
   - **H0 (нулевая гипотеза):** Разница средних `KL_cold - KL_hot <= 0`.
   - **H1 (альтернатива):** `KL_cold - KL_hot > 0`.
   - Требуемый уровень значимости: \( p < 0.01 \).

4. **Визуализация**:
   - График "Mean KL Divergence vs Steps" с конвертами ошибок (shaded std).
   - График "Trace Fisher vs Steps" для демонстрации быстрого сглаживания у "hot".
